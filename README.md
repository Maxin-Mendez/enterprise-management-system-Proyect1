# Sistema de Gestión Empresarial
Aplicación de escritorio desarrollada con .NET Framework y C#, orientada a la administración y control de procesos empresariales como gestión de usuarios, clientes, inventario, servicios, planillas y facturación.

### 📌 Características Principales
- 👥 Gestión de usuarios
- 🧾 Administración de clientes
- 📦 Registro y control de almacén
- 💰 Gestión de ingresos y servicios
- 🧑‍💼 Planilla de trabajadores
- 🛒 Facturación de ventas
- 🔐 Control de acceso al sistema
- 📊 Interfaz administrativa intuitiva
