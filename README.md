# Sistema de Gestión Empresarial
Aplicación de escritorio desarrollada con .NET Framework y C#, orientada a la administración y control de procesos empresariales como gestión de usuarios, clientes, inventario, servicios, planillas y facturación.
<br>

### 📌 Características Principales
- 👥 Gestión de usuarios
- 🧾 Administración de clientes
- 📦 Registro y control de almacén
- 💰 Gestión de ingresos y servicios
- 🧑‍💼 Planilla de trabajadores
- 🛒 Facturación de ventas
- 🔐 Control de acceso al sistema
- 📊 Interfaz administrativa intuitiva
<br>

# 🛠️ Tecnologías Utilizadas
- C#
- .NET Framework
- Windows Forms
- Visual Studio
<br>

# ⚙️ Requisitos
Antes de ejecutar el proyecto, asegúrate de tener instalado:
- Visual Studio 2019 o superior
- .NET Framework
<br>

# 🚀 Instalación y Ejecución
1. Clonar el repositorio
```bash
  https://github.com/Maxin-Mendez/enterprise-management-system-Proyect1.git
```
2.  Abrir el proyecto\
Abrir la solución (.sln) desde Visual Studio.

3. Ejecutar el proyecto\
Presiona: 
```bash
  F5
```
<br>

# 📖 Funcionalidades del Sistema
| Módulo      | Descripción                          |
| ----------- | ------------------------------------ |
| Usuarios    | Administración y gestión de usuarios |
| Clientes    | Registro y gestión de clientes       |
| Almacén     | Control de productos e inventario    |
| Servicios   | Registro de ingresos y servicios     |
| Planilla    | Gestión de trabajadores              |
| Facturación | Generación de facturas de venta      |
